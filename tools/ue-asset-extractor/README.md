# wu138di通用UE资产提取器 v1.0（usmap版）

[使用教程与下载](../../README.md)

## 这个工具做什么

UE4 / UE5 游戏的资产要先有映射文件（`.usmap`），FModel 之类的查看器才能正确读出类结构与属性名。本工具读取正在运行的游戏进程生成 `游戏名.usmap`，不注入 DLL，也不改动游戏本体。

- 自动找出主程序：支持 Steam 安装、普通安装、多项目目录、附赠程序与扁平化安装。
- 自动识别引擎版本，覆盖 UE4 4.0—4.27、UE5 5.0—5.8；识别不足时弹出版本选择框。
- 已有映射先备份为 `游戏名.usmap.bak`，新映射校验通过后才替换。
- 只读取游戏进程；原本运行的游戏保持打开，工具自己启动的游戏在完成后请求正常关闭。

## 发布文件

- `wu138di.UE.Asset.Extractor.v1.0-Windows-x64.exe`：单文件程序，内置 Python 运行时，直接打开。

本目录只保存发布说明，可执行文件通过 [Releases](https://github.com/wu138di/wu138di_tools/releases/tag/ue-usmap-v1.0) 分发，不提交到 Git。

## 使用要点

1. 打开 EXE，选择游戏根目录。
2. 等待映射生成：首次运行会准备工具库，之后缓存在游戏目录的 `_usmap_export/tools`，可离线复用。
3. 提取成功后，游戏根目录出现 `游戏名.usmap`，在 FModel 中加载即可浏览、导出资产。

日志位于 `_usmap_export/oneclick.log`，出错时把日志发给作者即可。

## 范围与限制

- 面向 Windows x64 的 UE4 / UE5 游戏，不支持 UE1 / UE2 / UE3。
- 实测游戏：DontLie（UE5.4）、寂静岭 Townfall（实际 UE 5.6.1，参数 5.6）。
- “可选版本”不等于“每款游戏都已验证兼容”，特殊编译配置或读取受限的游戏可能仍需单独适配。
- 映射会经过结构、名称引用、枚举、类 / 结构、属性及核心引擎类检查，但不保证每个资产都能在 FModel 中逐项解析成功。
